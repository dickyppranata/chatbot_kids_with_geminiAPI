##AI Learning Assistant for Children

Website chatbot edukasi yang dirancang untuk membantu anak usia 10–14 tahun belajar secara interaktif menggunakan teknologi Artificial Intelligence.

Sistem memanfaatkan Google Gemini API sebagai mesin kecerdasan buatan dan menerapkan Few-Shot Prompting untuk mengarahkan model AI agar memberikan jawaban yang sederhana, ramah, dan sesuai dengan tingkat pemahaman anak.

Pengguna dapat memilih topik pembelajaran seperti Matematika Dasar, Sains, Bahasa Indonesia, dan Pengetahuan Umum, kemudian mengajukan pertanyaan melalui antarmuka chatbot. AI akan menjelaskan materi menggunakan bahasa yang mudah dipahami, memberikan contoh yang relevan, dan menawarkan latihan sederhana setelah pengguna memahami materi.
